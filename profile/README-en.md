# PSOURCE

**Open Source software for ClassicPress and WordPress.**

[🇩🇪 Deutsch](README.md) · [🇬🇧 English](README-en.md) · [Our Motivation](MOTIVATION.md)

PSOURCE (Power-Source) develops, modernizes and maintains free Open Source software for **ClassicPress and WordPress**.

Our focus is on practical solutions for websites, communities, Multisite networks, e-commerce and small businesses — with a strong emphasis on **control, privacy, clean code and long-term maintainability**.

PSOURCE has grown out of real-world projects and real-world requirements over many years. What started as the continuation of abandoned or outdated projects has gradually evolved into a growing ecosystem of interconnected tools.

---

## 🧩 What is PSOURCE?

PSOURCE is not a single product, nor is it simply a collection of unrelated plugins.

Many projects can be used independently, while others complement each other and extend each other's functionality. This allows individual tools to become part of more comprehensive solutions for complex projects.

Some projects originated as older WordPress plugins that were no longer maintained by their original developers. Others have been extensively rebuilt or developed from the ground up over time.

**Good Open Source software does not have to disappear just because its original developer moves on.**

PSOURCE aims to preserve, modernize and meaningfully evolve such projects — allowing new software to grow from the ideas and work that came before.

---

## 🌱 A Growing Ecosystem

PSOURCE has grown organically over many years.

Some of the software was created out of the practical need to keep existing projects and long-established client installations running for the long term. Especially with complex WordPress Multisite environments, replacing working systems with completely different solutions is often simply not a realistic option.

So the work began: learning, fixing, modernizing, extending and maintaining.

Over time, individual projects became entire tool suites. Some were consolidated into smaller suites, others were fundamentally rebuilt. At the same time, more and more original development was added.

The result is an ecosystem where different PSOURCE projects can complement and extend one another.

## 🛠️ ClassicPress & WordPress

PSOURCE supports **ClassicPress and WordPress**.

ClassicPress has a special place in the project: many PSOURCE projects are developed with the goal of expanding what ClassicPress can do and helping build a strong ecosystem of plugins, themes and developer tools around it.

At the same time, support for WordPress is deliberately maintained.

**This is not about WordPress versus ClassicPress.**

It is about choosing the right tool for a particular project.

That is why PSOURCE projects can be useful for both ClassicPress and WordPress — and in many cases can be used on both platforms.

For older projects, modernization often means:

- replacing deprecated APIs
- improving PHP compatibility
- modernizing JavaScript
- reducing obsolete jQuery dependencies
- fixing security issues
- improving WordPress and ClassicPress compatibility
- preserving and extending existing functionality
- bringing older projects back to life for modern environments

The principle is simple:

**Modernize without unnecessarily breaking working projects.**

## 🔒 Control, Privacy & Independence

PSOURCE believes that people should remain in control of their own software and their own data.

For this reason, PSOURCE projects aim to avoid unnecessary dependencies on external services.

This means, wherever practical:

- no unnecessary cloud dependencies
- no mandatory SaaS services
- local processing whenever possible
- transparent Open Source code
- no artificial limitations where they are technically unnecessary
- GPL-based software

Of course, individual projects may integrate with or require external services for specific functionality. The relevant requirements and privacy information are always documented in the repository of the respective project.

## 🧑‍💻 For Developers

PSOURCE is not intended to be a closed product.

The projects are meant to provide a foundation that other developers can build upon.

Bug fixes, improvements, translations, new features and independent extensions are welcome.

Some projects are forks or continuations of older Open Source projects. Others have evolved far beyond their original codebase, while some are entirely original developments.

As a result, repositories may contain different development stages and historical structures.

That is part of their history.

The goal is not to hide that history, but to use it as a foundation for **maintainable and future-proof software**.

## 🌍 Growing Internationally

PSOURCE has its roots in Germany, and many projects were originally developed with German requirements in mind — including areas such as privacy, taxation, e-commerce and legal requirements.

The project therefore continues to have a strong focus on **German and European requirements**.

At the same time, PSOURCE is now beginning to grow internationally.

English translations, documentation and contributions from other countries are very welcome.

PSOURCE does not aim to cover every region by itself.

**If someone wants to adapt a project to their own language, country or requirements, that is exactly what Open Source is for.**
